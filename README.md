# Lexivue

Мінімалістичний веб-додаток для вивчення англійської мови через YouTube-відео для українців (адаптований під ПК та iPhone 13).

## Можливості
- **YouTube + субтитри в реальному часі** з пословним підсвічуванням того слова, яке зараз звучить у відео.
- **Миттєвий переклад на українську** одним натисканням на будь-яке слово (з транскрипцією, озвучкою та перекладом контексту).
- **Режим читання** — текст із відео без таймкодів або будь-який власний англійський текст.
- **Двосторонні 3D-карточки** для повторення збережених слів (з підтримкою свайпів на iPhone 13).

## Локальний запуск
```bash
npm install
npm run dev
```

## Хостинг (Vercel)
Оскільки застосунок використовує серверну частину (`/api/transcript` та `/api/translate`), для постійного безкоштовного хостингу підключіть цей GitHub-репозиторій на [vercel.com](https://vercel.com) — усе вже налаштовано через `vercel.json` та функції у папці `api/`.
